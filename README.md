# CodeAlpha UI/UX Internship

This repository contains the UI/UX design tasks completed as part of the **CodeAlpha UI/UX Design Internship**.

## Completed Tasks

### Task 1 – Wireframing & Low-Fidelity Design

* Designed low-fidelity wireframes for a mobile application.
* Focused on user flow, layout planning, and navigation.
* Tool Used: Figma

### Task 2 – High-Fidelity UI Design

* Converted the wireframes into high-fidelity user interface designs.
* Applied color palette, typography, icons, and modern UI principles.
* Tool Used: Figma

### Task 3 – UX Case Study

* Conducted a UX case study on an existing application.
* Analyzed the user journey, identified strengths and weaknesses, and proposed design improvements.
* Tool Used: Figma / PDF
